# BugFix-261020-0002: 修复导出 Markdown 按钮无反应及单页配音切换页面导致音频存错页面的缺陷

## 一、缺陷描述
1. **导出 Markdown 按钮点击无响应**：
   在“步骤 2：编辑文案”工具栏点击【导出 Markdown】按钮时，界面没有任何弹窗、文件保存提示或反应。
2. **异步合成期间切换页面导致音频错位写错页面**：
   在某一页（例如第 2 页）点击【生成配音】后，因网络 TTS 耗时若干秒，用户在等待期间切换到第 3 页，当第 2 页的配音合成完毕返回时，生成的音频地址和时长被错误地写入了当前所在的第 3 页，导致第 2 页没有音频，而第 3 页音频被错误覆盖。

## 二、测试分析与根因排查
1. **导出 Markdown 无响应根因**：
   原实现依赖前端浏览器标准的 `URL.createObjectURL(blob)` 与 DOM 模拟点击 `<a download>`：
   ```typescript
   const a = document.createElement("a");
   a.href = URL.createObjectURL(blob);
   a.download = `${project.value.ppt_stem}_scripts.md`;
   a.click();
   ```
   在 Tauri (Windows WebView2) 桌面环境下，WebView2 默认拦截原生 blob 下载链接或静默丢弃下载事件，导致点击没有任何反应。桌面端应用应当使用系统原生的“另存为”对话框（`rfd::FileDialog::save_file`）直接持久化文件到指定路径。
2. **异步配音存储错位根因**：
   原 `handleSynthesizeSingle` 函数中直接使用了动态计算属性 `currentSlide.value`：
   ```typescript
   const updated = await invoke<SlideInfo>("synthesize_slide_cmd", {
     slideIndex: currentSlide.value.index,
     text: currentSlide.value.script_text,
     ...
   });
   currentSlide.value.audio_path = updated.audio_path;
   currentSlide.value.audio_duration = updated.audio_duration;
   ```
   因为 `currentSlide` 是 `computed(() => project.value.slides[selectedSlideIdx.value])`，用户在 `await` 网络等待期间若修改了 `selectedSlideIdx` 切换至其他幻灯片（如第3页），`await` 返回后 `currentSlide.value` 已指向第 3 页对象，导致第 2 页合成的音频直接覆盖到了第 3 页。

## 三、修复方法与实现
1. **原生文件对话框导出/导入 Markdown**：
   - 在 Rust 后端实现 `export_markdown_cmd`，调用 `rfd::FileDialog::new().save_file()` 调起原生 Windows 另存为窗口，默认文件名设为 `${ppt_stem}_scripts.md`，选定路径后通过 Rust 标准库直接写入并返回保存路径；
   - 在前端 `handleExportMd` 中调用 `export_markdown_cmd`，保存成功后弹出成功提示路径；
   - 同时将 `handleImportMd` 升级为 Rust 端原生的 `import_markdown_cmd`，解决 WebView `<input type="file">` 潜在的焦点拦截问题。
2. **锁定发起合成时的目标幻灯片，杜绝页面错位**：
   - 在 `handleSynthesizeSingle` 中进入异步前，先局部锁定发起合成的目标幻灯片索引与对象（`targetSlide`、`targetIndex`）；
   - 在 `invoke` 异步完成返回后，通过 `project.value.slides.find(s => s.index === targetIndex)` 精确更新目标幻灯片的 `audio_path`、`audio_duration` 及 `audio_versions`，无论用户当前停留在哪一页，均绝不会写入非目标页面；
   - 增加 `synthesizingSlideIndex` 状态追踪：
     - 左侧幻灯片缩略图在正在合成的页面上显示带有动态呼吸效果的 `⏳ 合成中` 徽标；
     - 底部合成按钮在用户切到其他页面时动态显示 `第 X 页合成中...` 并保持禁用，给予用户明确的异步执行视觉反馈。

## 四、涉及与修改代码清单
- `src-tauri/src/commands.rs` & `src-tauri/src/lib.rs`: 
  - 新增 `export_markdown_cmd`（原生另存为文件对话框与落盘）；
  - 新增 `import_markdown_cmd`（原生文件选择对话框与读取）；
- `src/App.vue`: 
  - 改造 `handleExportMd` 与 `handleImportMd` 接入后端原生命令；
  - 改造 `handleSynthesizeSingle`，闭包锁定 `targetIndex` 并精确匹配更新目标幻灯片；
  - 引入 `synthesizingSlideIndex` 响应式变量，支持左侧缩略图 `⏳ 合成中` 与底部按钮动态状态提示；
  - 增加 `.synthesizing-badge` 动画样式；
- `release_portable/PPTVideoGenerator.exe`:
  - 重新编译 Release 便携二进制并部署。
