# R-261013-0001: PPT 视频生成器 Rust + Tauri 桌面端重构与多角色便携架构

## 一、变更背景与原因
原应用基于 Python + Web 界面运行，存在依赖环境庞大（需安装 Python、虚拟环境及诸多三方包）、跨平台桌面启动慢、打包体积大等问题。为了实现零依赖“单 EXE 即开即用”的便携桌面体验，同时落实 2026年10月13日提出的多角色独立语速调节、停顿语法支持与 TTS 接口配置化等需求，决定采用 Rust + Tauri v2 + Vue 3 进行全新重构。

## 二、变更具体内容
1. **多角色音色与独立语速配置**：
   - 预设“角色1/2/3”，各角色支持独立调节语速（0.5x ~ 2.0x）与音色绑定。
   - 解析文案首个 `{role:角色名}` 自动绑定至角色1；未指定角色的文案默认由角色1兜底。
   - 多角色朗读交替段落自动插入 300ms 静音切片平滑过渡。
2. **停顿语法 SSML 转换**：
   - 支持脚本中书写 `[break=100ms]` 停顿标记，在调用 TTS 前自动转为 SSML `<break time="100ms"/>`。
3. **TTS 端点自由配置**：
   - 新增 API Base URL 配置项，既支持阿里云 DashScope 云端服务，也支持本地私有部署端点。
4. **便携模式（Portable Architecture）**：
   - 程序自动检测所在目录下是否存在 `config.json` 与 `tools/` 目录；若存在则以程序同级目录管理 `projects/` 和 `output/`，无需污染用户全局目录。
5. **高性能并发合成**：
   - 底层集成 FFmpeg/FFprobe，实现逐页静音/配音切片极速拼接与 MP4 视频合成。

## 三、涉及与修改的代码文件
- `src-tauri/src/models.rs`: 数据结构定义（RoleVoiceConfig, SlideInfo, ProjectState, AppConfig）
- `src-tauri/src/config.rs`: 便携模式路径解析与配置读写管理
- `src-tauri/src/ppt_parser.rs`: PowerShell + Office COM 演示文稿切片提取器
- `src-tauri/src/tts_service.rs`: 多角色解析、SSML 停顿转义、静音拼接与 TTS HTTP 调用
- `src-tauri/src/video_composer.rs`: FFmpeg 视频切片生成与无缝 Concat 拼接
- `src-tauri/src/project_manager.rs`: 项目工程目录创建、project.json 归档持久化
- `src-tauri/src/commands.rs`: Tauri IPC 通信指令集
- `src-tauri/src/lib.rs`: Tauri 应用上下文与插件注册
- `src/App.vue`: Vue 3 桌面端核心交互界面
