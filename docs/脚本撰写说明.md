# PPT 视频生成器 · 脚本撰写说明

## 一、软件简介

PPTVideoGenerator 是一个 PPT 转视频桌面工具：导入 PPT → 为每页撰写朗读脚本 → 自动进行多角色语音合成 → 一键生成带配音（可选字幕）的 MP4 视频。

本说明仅介绍**脚本如何撰写**，以及与其配套的角色音色、TTS 接口设置。

---

## 二、脚本语法（核心）

脚本支持 **角色切换**、**精确停顿**、**自然停顿** 三种控制方式，可自由组合。

### 1. 角色切换：`{role:角色名}`

在任意位置写 `{role:李磊}`，表示**从此处开始**切换为「李磊」这个角色的音色与语速。

规则：

| 规则             | 说明                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| 角色数量         | 固定 3 个槽位（角色 1 / 角色 2 / 角色 3）                                |
| 首个角色自动绑定 | 脚本中**首次出现**的角色标签（如 `{role:李磊}`）会自动填入**角色 1**     |
| 未指定角色的段落 | 脚本中没有角色标签的段落，**统一使用角色 1** 的音色与语速                |
| 角色名不匹配     | 角色名与「多角色音色配置」面板中填写的角色名不一致时，**兜底使用角色 1** |
| 切换过渡         | 角色切换时自动插入 **300ms 静音**，保证对话自然不粘连                    |

> 注意：`{role:角色名}` 里的角色名必须与「生成视频」页中该角色填写的**脚本中对应的角色名**完全一致（前后空格会被忽略）。

### 2. 精确停顿：`[break=100ms]`

在需要精确停顿的位置写 `[break=时长]`，支持 `ms` 和 `s` 两种单位：

| 写法            | 实际停顿                       |
| --------------- | ------------------------------ |
| `[break=100ms]` | 100 毫秒                       |
| `[break=1.5s]`  | 1.5 秒                         |
| `[break=500]`   | 500 毫秒（不写单位按毫秒处理） |

### 3. 换行 = 自然停顿

- 脚本中的**换行**会自动转为全角逗号，为 TTS 提供自然停顿；
- 连续多个逗号会自动合并为一个，避免产生异常停顿。

### 4. 每页字幕（可选）

- 字幕总开关在「系统设置」页，默认关闭；
- 开启后，**默认使用本页朗读文案作为字幕**（自动去除 `{role:}`、`[break=]` 等标记）；
- 也可以在编辑页为单页单独填写「字幕文案」，留空则复用朗读文案。

## 三、脚本示例

以下是一页 PPT 的完整脚本示例（旁白 + 双角色对话 + 停顿）：

```
{role:旁白}欢迎收看本期产品介绍。

{role:主持人}大家好，我是主持人小李，很高兴和大家见面。
{role:嘉宾}大家好，我是嘉宾小张。[break=500ms]非常荣幸来到节目现场。

{role:主持人}小张，先给观众做个自我介绍吧。
{role:嘉宾}好的，我是一名软件工程师，专注桌面应用开发。[break=1s]平时喜欢研究音视频与人工智能技术。
```

对应效果：

| 脚本内容                        | 效果                                                  |
| ------------------------------- | ----------------------------------------------------- |
| `{role:旁白}` 开头              | 「旁白」自动填入角色 1，此后未标注段落均用角色 1 音色 |
| `{role:主持人}` / `{role:嘉宾}` | 切换对应角色的音色与语速，切换处自动插入 300ms 静音   |
| `[break=500ms]`                 | 嘉宾说完后精确停顿 0.5 秒                             |
| `[break=1s]`                    | 停顿 1 秒，突出段落节奏                               |
| 空行换行                        | 转为自然停顿的逗号                                    |

## 四、多角色音色配置

在「生成视频」页配置三个角色的音色与语速：

| 槽位   | 音色选项                                                                        | 语速范围    | 说明                                   |
| ------ | ------------------------------------------------------------------------------- | ----------- | -------------------------------------- |
| 角色 1 | 知性女声 `longyingjing_v3` / 阳光男声 `longanyang` / 温柔女声 `longxiaochun_v2` | 0.5x ~ 2.0x | **默认兜底角色**，所有未匹配段落用它   |
| 角色 2 | 同上三种音色                                                                    | 0.5x ~ 2.0x | 需在「脚本中对应的角色名」中填写角色名 |
| 角色 3 | 同上三种音色                                                                    | 0.5x ~ 2.0x | 需在「脚本中对应的角色名」中填写角色名 |

## 五、TTS 接口配置（系统设置页）

语音合成默认调用**阿里云百炼（DashScope）**云端服务，需联网并配置 API Key：

| 配置项                      | 填写内容                                                                                      |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| API 接口调用地址 (Base URL) | `https://dashscope.aliyuncs.com/api/v1/services/audio/tts/generation`（默认值，留空自动使用） |
| API Key                     | `sk-...`，在阿里云百炼控制台（bailian.console.aliyun.com）→ API-KEY 管理中获取                |
| TTS 模型名称                | `cosyvoice-v3-flash`（默认，可按需更换）                                                      |

也支持：

- **本地 CosyVoice 服务**：填 `http://127.0.0.1:8890`，API Key 可留空；
- **OpenAI 兼容端点**：填 `https://dashscope.aliyuncs.com/compatible-mode/v1/audio/speech` 或其他兼容地址。

## 六、目录与文件说明

```
PPTVideoGenerator/
├── PPTVideoGenerator.exe       # 主程序（内置全部界面与逻辑）
├── config.json                 # 配置文件（TTS 接口 / 角色 / 字幕 / 视频参数，首次运行自动生成）
├── tools/
│   ├── ffmpeg.exe              # 视频合成引擎
│   └── ffprobe.exe             # 音视频探测工具
├── projects/                   # 工程数据（PPT 切片、各页音频版本，自动创建）
└── output/                     # 最终生成的 MP4 视频（自动创建）
```

> 提示：若 `config.json` 由他人配置后随包分发，其中包含其 **API Key**。如需对外分发且不想泄露密钥，请删除 `config.json`（程序会自动生成默认配置，由使用者自行填写 API Key）。

## 七、常见问题

| 问题              | 处理                                                             |
| ----------------- | ---------------------------------------------------------------- |
| 合成失败 / 无声音 | 检查网络与 API Key 是否正确；本地接口请确认服务已启动            |
| PPT 无法导入      | 本机需安装 Microsoft Office（用于解析 PPT 切片）                 |
| 生成的视频在哪里  | 程序同级目录 `output/` 下，文件名含工程名与时间戳                |
| 字幕不显示        | 到「系统设置」页打开字幕开关；系统需存在所选字体（默认微软雅黑） |
