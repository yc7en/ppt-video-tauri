# R-261017-0001: 字幕功能（硬字幕烧录 + 精准计时）

## 一、变更背景与原因
生成的视频仅有画面与配音，缺少字幕，不利于无声观看与信息传达。需要一项可开关的字幕功能，且字幕时间要尽量贴合语音，避免"声音已过、字幕还在"的错位。

由于现有本地/自建 TTS（HTTP）不返回字级时间戳，采用"逐句合成 + ffprobe 实测每句真实时长"的方式获得句级精确时间轴；对旧音频或无法切段的情况退化为按字数比例估算。

## 二、变更具体内容
1. **设置页总开关**：`SubtitleConfig.enabled` 随 `app_config` 写入 `config.json`；关闭时合成完全跳过字幕逻辑，零开销。
2. **基础样式配置**：字体名称、字号、字体颜色、描边颜色、描边宽度、底部边距、每行最大字数、同时最大行数、计时模式（segment/estimate）。
3. **精准计时（T2）**：合成配音时把整页文案切分为「句子 / `[break]` 停顿 / 角色切换」片段，逐段合成并用 `ffprobe` 实测时长，按"角色切换 300ms、同角色句间 `sentence_gap_ms`、显式 break 指定时长"插入空隙后拼接；据此累加得到整页精确时间轴，写入与音频版本同名的旁车文件 `audio/slide_XXXX/{timestamp}.timing.json`。
4. **估算兜底（T3）**：无旁车文件（旧音频）或切段失败时，按每行字数比例分配整页时长。
5. **字级样式烧录**：合成视频时读取旁车 → 生成 ASS → 通过 FFmpeg `ass` 滤镜烧录到画面底部居中；以相对文件名 + `current_dir` 方式规避 Windows 路径转义问题。
6. **字幕文案覆盖**：每页可选填独立字幕文案（`SlideInfo.subtitle_text`），留空则复用朗读文案（自动剥离 `{role:}`/`[break=]`/`<speak>` 标记）。
7. **编辑页可视化**：预览图叠加字幕样式预览；显示该页"字幕计时：精确/估算"小标；切换配音版本时联动刷新。

## 三、涉及与修改的代码文件
- `src-tauri/src/models.rs`: 新增 `SubtitleConfig`、`TimingMode`；`AppConfig.subtitle`、`SlideInfo.subtitle_text`、`TtsConfig.sentence_gap_ms`（均 `serde(default)` 兼容旧文件）
- `src-tauri/src/subtitle_service.rs`: 新增。文本清洗、计时旁车读写、`build_cues`（对齐/估算）、`build_ass`、颜色与时间格式化
- `src-tauri/src/tts_service.rs`: 新增 `ScriptSegment`、`segment_script`、`generate_silence_mp3`、`write_timing`、`synthesize_slide_audio_with_timing`（T2 逐段实测）
- `src-tauri/src/video_composer.rs`: `compose` 增加 `subtitle_cfg`，逐页生成 ASS 并追加 `ass` 滤镜烧录
- `src-tauri/src/commands.rs`: `synthesize_slide_cmd` 落计时旁车、`compose_video_cmd` 增加 `subtitle_config` 入参、新增 `probe_timing_mode_cmd`
- `src-tauri/src/ppt_parser.rs`: `SlideInfo` 初始化补充 `subtitle_text`
- `src-tauri/src/lib.rs`: 注册 `subtitle_service` 模块与 `probe_timing_mode_cmd`
- `src/App.vue`: 设置页字幕分组（含总开关）、编辑页字幕覆盖框与叠层预览、生成页传参、计时来源探测

## 四、已知限制
- 精准计时为句级；同一句折行成多条字幕时在该句区间内按字数比例细分。
- 字幕覆盖文案与朗读文案差异较大时无法逐字对齐，退化为按句序/比例对齐。
- 依赖系统字体（默认 Microsoft YaHei）。
