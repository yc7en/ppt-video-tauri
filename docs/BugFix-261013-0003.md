# BugFix-261013-0003: 修复文件选择弹窗黑色控制台窗口与冷启动卡顿

## 一、缺陷描述
在第一步点击【📁 选择文件...】或【📂 浏览 project.json...】时，系统会弹出 PowerShell 黑色控制台终端窗口，并且界面卡顿 2~4 秒后才显示文件选择框，严重影响交互流畅度与桌面应用质感。

## 二、修复方法与实现
1. **根因定位**：
   - 原代码使用 `std::process::Command::new("powershell")` 执行脚本调起 .NET WinForms 对话框；
   - 每次点击均会产生子进程创建开销、PowerShell 引擎与 CLR 运行时冷启动延迟（约 2~4 秒）；
   - 在 Windows GUI 桌面环境下未配置控制台静默参数，系统自动分配并弹出了控制台黑窗口。
2. **修复措施**：
   - 引入 Rust 原生文件对话框库 `rfd`（Rust File Dialog），直接在当前进程内调用 Windows 底层 Win32 COM `IFileDialog` 原生 C 接口，彻底消除外部子进程拉起开销，实现 **0 延迟秒开**；
   - 在底层的 PPT Office 导出与 FFmpeg 视频合成调用中统一设置 `creation_flags(0x08000000)`（`CREATE_NO_WINDOW`），全面压制所有后台子进程控制台黑窗。

## 三、涉及与修改代码清单
- `src-tauri/Cargo.toml`: 引入 `rfd = "0.17"` 原生 Win32 文件对话框依赖
- `src-tauri/src/commands.rs`: 使用 `rfd::FileDialog` 替换原 PowerShell 实现
- `src-tauri/src/ppt_parser.rs`: PowerShell 进程增加 `CREATE_NO_WINDOW` 标志
- `src-tauri/src/video_composer.rs`: FFmpeg 进程增加 `CREATE_NO_WINDOW` 标志
