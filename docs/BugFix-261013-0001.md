# BugFix-261013-0001: 修复 Windows PowerPoint COM 解析 0x800C000E 路径异常

## 一、缺陷描述
在第一步选择 PPT 文件并点击“开始解析”后，系统报错：
`PowerPoint 解析失败: HRESULT: 0x800C000E: Presentations.Open(...) COMException`。
该缺陷导致用户无法将 PPT 演示文稿切片导出为图片，阻碍后续所有流程。

## 二、修复方法与实现
1. **根因定位**：
   Rust 标准库中的 `std::fs::canonicalize()` 在 Windows 平台上会将路径规范化为含有超长路径前缀 `\\?\` 的扩展字符串（如 `\\?\C:\Users\...`）。然而微软 Office PowerPoint COM 接口对这种 verbatim 路径格式不兼容，从而抛出 COMException（0x800C000E）。
2. **修复措施**：
   在传递给 PowerShell COM 脚本前，对输入和输出路径执行 `.trim_start_matches(r"\\?\")` 处理，确保传入 PowerPoint API 的均为符合 Windows 传统标准格式的路径。

## 三、涉及与修改代码清单
- `src-tauri/src/ppt_parser.rs`: 剥离 `\\?\` 前缀，重构 PowerShell 导出脚本中的路径参数传值
