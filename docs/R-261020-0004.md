# R-261020-0004: 音色库配置扩展与唯一默认兜底音色设定功能

## 一、变更背景与原因
1. **音色定制受限**：原系统中各角色的发音人音色为硬编码预设的 3 种音色（`longyingjing_v3` 知性女声、`longanyang` 阳光男声、`longxiaochun_v2` 温柔女声），用户无法选择或添加 CosyVoice 模型支持的其他官方音色或自定义发音人（例如配置「龙安欢」对应 `longanhuan_v3`）。
2. **唯一默认兜底需求**：在多角色配音或未标记角色（如未指定 `{role:xxx}` 或角色名无法匹配）的文案段落中，系统需要一个明确且可自定义的唯一默认兜底音色，使得用户能自由指定全局兜底发音人。

## 二、变更具体内容
1. **数据模型升级与持久化**：
   - 在 Rust 后端 `models.rs` 中新增 `VoiceItem` 结构体（包含 `name`、`voice` 与 `is_default` 属性）；
   - 在 `AppConfig` 全局配置中新增 `custom_voices: Vec<VoiceItem>` 字段，预置知性女声、阳光男声、温柔女声，默认以知性女声为兜底，并支持向后兼容反序列化；
   - `AppConfig` 提供 `get_default_voice()` 方法，TTS 音频生成遇到空缺角色时动态获取用户设定的唯一兜底音色。
2. **界面交互增强（步骤 3、步骤 2 与步骤 4 同步支持）**：
   - **步骤 3（多角色音色配置）**：标题栏右侧新增显眼的 `➕ 增加音色` 按钮，各角色音色下拉框动态读取音色库全部可用发音人，并实时标注 `⭐ [默认兜底]`；
   - **步骤 2（文案编辑内嵌角色栏）**：标签栏右侧增加 `➕ 增加音色` 快捷按钮，角色下拉框同步响应最新音色库；
   - **步骤 4（系统设置）**：新增「🎙 音色库配置与默认兜底」卡片，清晰展示所有已配置音色，支持直接设为唯一默认兜底或删除自定义音色。
3. **音色库配置与新增弹窗 (`showVoiceModal`)**：
   - **增加新音色表单**：输入音色显示名称（如：`龙安欢`）、音色代码/Voice ID（如：`longanhuan_v3`），支持一键勾选「设为唯一默认兜底值」；
   - **常用音色快捷填入**：提供龙安欢 (`longanhuan_v3`)、龙小夏 (`longxiaoxia`)、龙硕 (`longshuo`) 等快捷填入标签，方便快速录入；
   - **唯一默认兜底值设定机制**：当任意音色被设为默认兜底时，互斥确保全局仅有一个音色具有 `is_default: true` 标记，并自动联动角色 1 同步更新且持久化至 `config.json` 与 `project.json`；
   - **安全删除限制**：当前作为唯一默认兜底的音色禁止直接删除，防止兜底丢失。

## 三、涉及与修改的代码文件
- `src-tauri/src/models.rs`:
  - 定义 `VoiceItem` 结构与 `default_voices` 函数；
  - `AppConfig` 增加 `custom_voices` 字段与 `get_default_voice()` 兜底查找方法。
- `src-tauri/src/tts_service.rs`:
  - 动态从 `load_config().get_default_voice()` 获取唯一默认兜底音色，替代原先写死的 `longyingjing_v3`。
- `src/App.vue`:
  - 模板中在步骤 2、步骤 3、步骤 4 分别增加 `➕ 增加音色` 触发入口与音色库配置卡片；
  - 增加音色库配置与新增的居中模态弹窗；
  - 脚本中实现 `availableVoices` 响应式列表、`handleAddNewVoice`、`handleSetDefaultVoice`、`handleDeleteVoice`、`fillVoicePreset` 等核心逻辑；
  - 补充暗色调质感 CSS 弹窗与音色列表高亮徽章样式。
- `release_portable/PPTVideoGenerator.exe`:
  - 重新编译 Release 二进制并部署。

## 四、测试与验证
1. 打开多角色音色配置，点击【➕ 增加音色】，通过快捷标签填入「龙安欢」与「longanhuan_v3」，勾选「设为唯一默认兜底值」并保存；
2. 检查音色列表中「龙安欢」被成功标记为「⭐ 唯一默认兜底」，原知性女声的兜底标记自动取消；
3. 检查步骤 2 与步骤 3 的音色下拉选择框，均已包含「龙安欢 (longanhuan_v3) ⭐ [默认兜底]」，且角色 1 自动同步切换为该兜底音色；
4. 退出程序并重新打开，配置完好保留。
