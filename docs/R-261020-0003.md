# R-261020-0003: 清空文案按钮防误触右移与批量自动合成全部队列功能

## 一、变更背景与原因
1. **清空文案按钮误触风险**：原【🗑 清空文案】按钮与【导入 Markdown】、【导出 Markdown】并排紧靠位于工具栏左侧，用户在常规导入导出操作时容易误触清空，虽有确认弹窗但存在操作风险与视觉干扰。用户需求将其移至最右侧（与右边沿对齐），与其他操作隔离。
2. **多页配音效率痛点**：对于拥有数十页 PPT 的项目，用户此前需要逐页点击进入编辑区，再逐页点击「⚡ 开始语音合成」；或者切换页面，容易漏配且繁琐。用户需求新增【⚡ 批量合成全部】按钮，能够一键自动建立合成队列，逐页顺序完成配音并实时保存，支持合成状态提示与随时优雅中止。

## 二、变更具体内容
1. **工具栏布局重构（右对齐隔离危险操作）**：
   - 将 `script-toolbar` 划分为 `.toolbar-left` 与 `.toolbar-right` 两个弹性布局区域；
   - **左侧工作流按钮组**：保留 `[📥 导入 Markdown]`、`[📤 导出 Markdown]`，并新增高亮渐变样式的 `[⚡ 批量合成全部]` 按钮；
   - **右侧辅助与危险操作区**：语法提示文本 `提示：支持 {role:角色名}...` 与 `[🗑 清空文案]` 按钮放置于右侧，并通过 `margin-left: auto` 和 `margin-right: 0` 严格与窗口右边沿对齐，杜绝误触。
2. **【批量合成全部】顺序队列机制 (`handleToggleBatchSynthesize`)**：
   - **有效页自动筛选**：遍历全部幻灯片，自动过滤出有文案内容的幻灯片清单（若全无文案则弹窗提示）；
   - **串行顺序调度**：依次对每个非空页面调用后台 `synthesize_slide_cmd` 接口，左侧缩略图栏实时展示当前正在合成的页面的「⏳ 合成中」动态角标，并在合成完成后自动刷新为「🎵 已配音」；
   - **即时落盘与进度同步**：每页合成完毕立即同步至 `project.slides[idx]`、重新计算幻灯片时长并调用 `save_project_cmd` 持久化保存至 `project.json`，即使中途终止也不会丢失已完成页面的音频；
   - **状态双向联动与优雅中止**：
     - 按钮动态显示为 `⏹ 停止批量合成 (X/Total)`，配有呼吸灯告警动画；
     - 底部单页合成按钮同步显示 `批量中 (X/Total)...` 并进入锁定状态，防止单页与批量并发冲突；
     - 点击「停止批量合成」按钮可即时发出中止指令，当前正在执行的单页合成完毕后队列安全停止，弹出已完成页数反馈；
   - **单页容错保障**：某页合成发生网络或接口异常时，记录错误提示并继续处理后续页面，避免单页异常导致整个批处理队列崩溃。

## 三、涉及与修改的代码文件
- `src/App.vue`:
  - 模板更新：重组 `script-toolbar` 为 `toolbar-left` 与 `toolbar-right`，加入批量合成按钮；
  - 逻辑更新：新增 `isBatchSynthesizing`、`batchProgressCurrent`、`batchProgressTotal`、`stopBatchRequested` 响应式状态与 `handleToggleBatchSynthesize` 队列控制函数；
  - 样式更新：新增 `.toolbar-left`、`.toolbar-right`、`.tool-btn.primary-glow`（渐变发光）、`.tool-btn.primary-glow.is-batching`（橙色脉冲呼吸）及 `.tool-btn.danger` 样式。
- `release_portable/PPTVideoGenerator.exe`:
  - 编译并部署最新便携 Release 执行程序。

## 四、测试与验证
1. 界面测试：检查步骤 2 脚本编辑工具栏，左侧为导入、导出、批量合成按钮，右侧紧靠右边缘为清空文案按钮，布局对齐美观；
2. 批量合成测试：在包含多页文案的项目中点击【⚡ 批量合成全部】，系统从第 1 页开始依序合成，侧边栏角标实时跟随变换，每页合成完毕自动落盘，支持中途安全点击中止。
