# R-261013-0003: 编辑文案页面布局重构与双向拖拽交互优化

## 一、变更背景与原因
在编辑文案（步骤 2）界面中：
1. 顶部上一页/下一页按钮与页码分散占据垂直空间，且幻灯片预览图默认高度仅 220px，在大分辨率屏幕下 PPT 文字难以看清；
2. 缩略图列表与文案编辑框尺寸固定，用户无法根据幻灯片复杂度和文案篇幅灵活调整各区域占比；
3. 窗口顶部无拖拽交互，用户无法便捷移动软件窗口。

## 二、变更具体内容
1. **底部控制栏重构（三段式布局）**：
   - 移除右侧顶部的“上一页/下一页”和“第 X/Y 页”，彻底释放上方视野。
   - 底部工具栏改为：左侧【🎤 生成配音】与试听时长，中间【第 X / Y 页】居中徽章，右侧【◀ 上一页】与【下一页 ▶】快捷导航。
2. **预览图默认占高扩至 2/3**：
   - 默认高度比例调整为 66.7%（2/3），PPT 内容大图高清居中展示。
3. **双向自由拖拽分割条（Resizable Splitters）**：
   - **左右拖拽**：缩略图列表与编辑区之间增加竖向拖拽条，宽度支持自由伸缩（带手柄悬浮高亮反馈）。
   - **上下拖拽**：预览图与文案文本框之间增加横向拖拽条，支持按需动态调配图片与文本输入区的高度分配比。
4. **窗口全角拖动支持**：
   - 在顶部导航栏及工具栏空白处配置 `data-tauri-drag-region`，支持点击任意空白边缘拖拽移动整个窗口。

## 三、涉及与修改的代码文件
- `src/App.vue`: 重构 Step 2 页面 HTML 结构、添加鼠标拖拽事件监听、优化 CSS Flex 弹性盒与拖拽手柄样式
