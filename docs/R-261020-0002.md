# R-261020-0002: 多角色音色配置新增【扫描角色】一键识别与自动填入功能

## 一、变更背景与原因
在多角色文案配音场景中，用户在前面各个幻灯片文案中撰写了 `{role:老师}`、`{role:同学}` 等角色标签。在视频生成（步骤 3）与文案编辑（步骤 2）中，用户期望在多角色音色配置标题右侧增加一个直观的【扫描角色】按钮，点击后能够一键自动扫描全篇文案中出现的角色，自动按次序填充到角色 1、角色 2、角色 3 的输入框中，并清理无效或残留的历史输入。

## 二、变更具体内容
1. **界面交互增强（步骤 3 与步骤 2 同步支持）**：
   - **步骤 3（生成视频）**：在「🎭 多角色音色配置」标题栏右侧（用户截图标注位置）增加显眼的 `🔍 扫描角色` 按钮；
   - **步骤 2（编辑文案）**：在嵌入式多角色配置工具栏中同步加入 `🔍 扫描角色` 按钮，无论在编辑文案还是在生成视频阶段均可随时调用。
2. **全量文案扫描与按序绑定逻辑 (`handleManualScanRoles`)**：
   - 遍历项目中所有幻灯片文案，依脚本顺序按正则匹配提取全部 `{role:角色名}` 标签并去重；
   - 将扫描到的角色按序重新填入对应槽位（首个角色对应角色 1、次个角色对应角色 2、第三个角色对应角色 3）；
   - 若文案中只有 2 个角色，会自动清空第 3 个槽位的残留输入，保证配置干净准确；
   - 自动调用 `handleRoleConfigChanged()` 即时将更新后的角色映射保存至 `project.json`；
   - 弹出反馈提示框，清晰告知扫描到的角色数量与对应填入的角色名称列表。

## 三、涉及与修改的代码文件
- `src/App.vue`:
  - 步骤 3 的 `section-title` 区域新增 `🔍 扫描角色` 按钮及弹性布局与悬浮微动样式；
  - 步骤 2 的 `editor-label-bar` 区域新增小型 `🔍 扫描角色` 快捷按钮；
  - 实现 `handleManualScanRoles` 扫描算法、槽位清洗赋值与项目保存逻辑；
- `release_portable/PPTVideoGenerator.exe`:
  - 重新编译 Release 便携二进制并部署。

## 四、测试与验证
- 在包含 `{role:老师}` 与 `{role:同学}` 的项目上测试点击【🔍 扫描角色】，系统精准识别出 2 个角色，角色 1 自动填入“老师”，角色 2 自动填入“同学”，第 3 个槽位自动置空，配置即时保存至 `project.json`。
